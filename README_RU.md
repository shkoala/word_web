# Word Web — «Поймай слово»

Готовая игра для уроков английского. Сохранены исходный лесной фон и четыре мухи. В версии 1.2 паук перерисован с восемью ногами, буквы увеличены и переставлены в новой SVG-паутине. Добавлен логотип ШКОАЛА. Весь интерфейс — на простом английском. Сборка, платные сервисы и сервер для самой игры не нужны.

## Быстрый запуск

1. Распакуйте архив **целиком**.
2. Откройте `index.html` в современном браузере. Папка `assets` и остальные файлы должны остаться рядом.
3. Введите слова или короткие фразы, каждую с новой строки, и нажмите **«Готово — играть»**.

В рабочей папке разработчика файлы сайта лежат в `dist/`. В скачиваемом архиве они уже вынесены в корень для удобной загрузки на GitHub.

## Размещение на GitHub Pages

1. Создайте репозиторий, например `word-web`. Для бесплатного GitHub Pages обычно используют публичный репозиторий.
2. Нажмите **Add file → Upload files**. Загрузите **содержимое** распакованного архива: `index.html` должен оказаться прямо в корне репозитория, а не во вложенной папке. Сохраните изменения кнопкой **Commit changes**.
3. Откройте **Settings → Pages**. В **Source** выберите **Deploy from a branch**, затем **main** и **/(root)**, нажмите **Save**.
4. Когда GitHub завершит публикацию, на этой же странице появится ссылка на игру. Откройте её и добавьте в закладки.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Все пути относительные, поэтому игра работает и по адресу вида `https://имя.github.io/word-web/`. Дополнительная настройка путей не нужна. Файл `.nojekyll` включён; если он не попал в загрузку через браузер, этому проекту он не критичен.

## Как играть

- Учитель задаёт свои слова. Поддерживаются английские буквы в обоих регистрах, пробел, точка, запятая, дефис и апостроф, до 32 символов в строке и до 200 строк. Регистр сохраняется: `Cat` и `cat` требуют разных ответов. Пустые строки игнорируются, лишние пробелы внутри фразы сокращаются до одного. Повторяющиеся слова сохраняются для повторения.
- При запуске муха со словом прилетает и останавливается внутри паутины. Цвета мух чередуются.
- Ученик нажимает на буквы **в нужном порядке**. Можно нажимать как на саму букву, так и на коричневую точку рядом с ней. Выбранные буквы записываются сверху.
- Начиная со второго щелчка между точками появляется нить. Повторный щелчок по той же букве записывает её снова и рисует петлю: например, `book`, `moon`, `see`. Повторные переходы в любую сторону получают отдельные дуги, с учётом всей паутины за раунд.
- Круглая кнопка **«пробел»** находится в центре, а остальные знаки (точка, запятая, дефис и апостроф) распределены внутри паутины. Нити проходят через соответствующую кнопку. **«⇧ A · 1 буква»** включает заглавную для следующей буквы и автоматически выключается после неё. Повторный щелчок отменяет режим. Пробелы и знаки не расходуют его. Кнопка режима сама не добавляет символ или нить.
- Ошибочная буква остаётся в ответе красной, неверная часть нити тоже краснеет. Муха трясётся, будто вырывается. Исправьте ошибку кнопкой **«Удалить букву»** или очистите ответ кнопкой **«Сбросить»**.
- Как только **всё** слово или фраза совпадает с заданием, муха летит к пауку и исчезает. Паук радуется и говорит **Yum!** Без страшных сцен.
- **«Следующее слово»** вызывает новую муху, очищает ответ и **сохраняет нити в общей паутине**. Для пропущенного задания сохраняется только верно набранное начало; ошибочные нити убираются. Между последней буквой старого задания и первой нового лишняя нить не рисуется. Автоматического перехода нет: учитель сам выбирает темп. На последнем слове кнопка меняется на **«Завершить»**.
- В конце показывается, сколько мух поймано, и миниатюра получившейся паутины. Повтор раунда или запуск нового списка начинает новую пустую паутину.
- В игровом режиме поле увеличено, чтобы буквы было легче читать. Паутина прикреплена нитями к деревьям, подвес паука продолжается до верха окна. Крепления перестраиваются при изменении размера экрана.

## Кнопки и уточнения

| Действие | Что происходит |
| --- | --- |
| Сбросить | Очищает буквы и нити **текущего слова**, сохраняет общую паутину прошлых слов и оставляет ту же муху. Если слово уже было собрано, текущая поимка отменяется, чтобы счётчик не удваивался при повторении. |
| Удалить букву | Убирает последнюю букву и последнюю нить. Работает и после правильного ответа: муха возвращается. |
| Следующее слово | Сохраняет правильные нити и переключает задание; незавершённое слово считается пропущенным, а не пойманным. |
| Слова | Возвращает к списку учителя. Список сохраняется в поле ввода. Кнопка «Готово — играть» начинает новый раунд с начала. |
| EN / RU | Переключает язык интерфейса, не сбрасывая текущее задание. |
| Звук | Необязательные короткие сигналы. Изначально выключены. |
| Полный экран | Раскрывает игру на весь экран, если браузер поддерживает эту возможность. |

Буквы можно вводить с английской клавиатуры, **Shift + буква** вводит заглавную, **Space** даёт пробел, **. , -** вводят соответствующие знаки, **Backspace** удаляет последний символ. Во время редактирования списка игровые клавиши не перехватываются. Удержание клавиши не вводит много одинаковых букв; для повтора нажмите её ещё раз.

Список учителя и настройки запоминаются только в этом браузере. На другом устройстве слова надо ввести заново. Сама игра не отправляет введённые слова на сервер.

Анимации и ожидающие действия отменяются при сбросе, удалении, смене слова и выходе к списку. Поздняя анимация старой мухи не может подменить новое задание. Если в системе включено уменьшение движения, анимации сокращаются.

## Файлы

- `index.html` — экраны и элементы управления.
- `styles.css` — оформление и адаптация к экрану.
- `core.js` — проверка списка, состояние раунда и координаты всех точек.
- `app.js` — клики, нити, анимации, звук, переключение языка.
- `assets/` — ваши исходные изображения с короткими именами файлов.
- `tests/core.test.cjs` — тесты основных игровых правил. При установленном Node.js: `node --test tests/core.test.cjs`.

Для загрузки на GitHub не нужно менять код или устанавливать Node.js. Не переименовывайте и не удаляйте папку `assets`.
