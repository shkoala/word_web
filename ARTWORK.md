# Word Web artwork refresh

The new spider was produced with the built-in image generator using the original spider/web picture as a style reference. The generated PNG was copied unchanged to `assets/spider-v3.png`; its transparent alpha channel is preserved.

## Final brief

Create only an isolated replacement spider in the original cheerful, glossy children's clipart style, on a genuinely transparent background. Warm caramel-orange and chestnut brown; kind sparkling eyes, a happy smile and rosy cheeks. Front-facing with a slight top-down view. Exactly eight jointed walking legs: four clearly separated legs and four distinct feet on each side, each attached to the cephalothorax. Fan the four legs on each side upward-outward, upper-outward, lower-outward and downward-outward. Show a rounded abdomen behind the smaller face-bearing cephalothorax. No antennae, wings, hands, extra appendages, letters, web, background or hanging thread. The game supplies the thread separately.

The exact 26-letter frame is a native SVG generated by `scripts/build-web.cjs`. It uses the game's coordinate data so visible letters, click targets and thread endpoints stay aligned. The supplied logo, background and fly assets have not been redrawn.
