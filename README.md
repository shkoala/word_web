# Spider spelling · Word Web

Игра для отработки написания английских слов и коротких фраз. Учитель вводит свои слова, ученик собирает их по буквам на паутине. Нити соединяют выбранные точки; повторяющиеся буквы создают петлю, пробел находится в центре.

Использованы предоставленные изображения: лесной фон, паутина с пауком и четыре мухи. Ошибка заставляет муху трястись, верный ответ отправляет её к пауку.

Локальный запуск: откройте `index.html`, сохранив рядом остальные файлы и папку `assets`.

Полная инструкция, правила и настройка GitHub Pages: [README_RU.md](README_RU.md).

Без сборки и внешних зависимостей. Тесты: `node --test tests/core.test.cjs`.
