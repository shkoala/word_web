## Следующая версия 1.1

Общая паутина за весь раунд, увеличенное игровое поле, крепления к деревьям и подвес паука до верхнего края. В центре — пробел, точка, запятая, дефис и заглавная для одной следующей буквы. Регистр заданий сохраняется. Сброс и удаление работают только с текущей попыткой; повтор раунда начинает новую паутину.

## Version 1.2: artwork and English interface

Large letters alternate common and less common letters around a new SVG frame. Vowels span the circle. A new transparent spider has eight distinct legs and no embedded hanging thread. The original SHKOALA logo is included. Fly words and answer letters are larger. The complete interface uses simple English.

The scattered controls now include an apostrophe. Straight and curly apostrophes are accepted, including in contractions and possessives. The cumulative web, return curves, reset, undo, scoring and fly animations are retained.

The working version before these changes is preserved in `before-art-refresh-2026-10-29`, at commit `e26177e959c4a00ca5f8cb1ef5ae3f6f3479c24c`.
